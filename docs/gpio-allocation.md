# GPIO Allocation

> AEGIS - Interface and GPIO Planning

Versão: 2.0
Estado: Planeamento Inicial

---

# Objetivo

Definir a utilização prevista das interfaces físicas e GPIOs do projeto AEGIS.

Este documento deve ser considerado a referência oficial para:

- atribuição de GPIOs
- utilização da Expansion Board
- reserva de interfaces
- prevenção de conflitos de pinagem

---

# Filosofia

O projeto AEGIS privilegia a utilização das Expansion Boards da Seeed Studio sempre que possível.

A arquitetura deve ser planeada com base em:

1. Interfaces lógicas
2. Conectores físicos
3. GPIOs individuais

A atribuição definitiva dos GPIOs apenas será realizada após a integração física dos componentes.
