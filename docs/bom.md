# Bill of Materials (BOM)

> AEGIS - Hardware Reference List

Versão: 2.0
Estado: Documento de Referência

---

# Objetivo

Este documento lista os componentes utilizados ou previstos para o projeto AEGIS.

Não representa o estado de aquisição nem de montagem.

O seu objetivo é servir como:

- referência de hardware
- lista de compras
- documentação técnica
- apoio à replicação do projeto

---

# Filosofia

Sempre que possível:

- utilizar componentes de baixo custo;
- privilegiar módulos populares;
- permitir substituições equivalentes;
- evitar dependências de fornecedores específicos.
